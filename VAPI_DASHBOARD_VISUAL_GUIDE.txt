YOUR WEBHOOK URL (use everywhere)
----------------------------------
https://portal.risebird.io/VapiInterviewCall/Webhook


WHERE TO SET WEBHOOK URL (BOTH PLACES)
---------------------------------------
1. Assistant → Server URL field
2. Tool (submitInterviewSlot) → server.url field
   (Or "Function" if you see older UI)

Both must have the same URL!
"Tools" and "Functions" work identically - just different naming!


WHAT THE ASSISTANT WILL DO
---------------------------
✅ Ask candidate: "What time works for you?"
✅ Wait for candidate to tell them a time
✅ Confirm: "Let me confirm - [DATE] at [TIME] IST. Correct?"
✅ After "yes", call submitInterviewSlot function
✅ Webhook receives data → Database updated

❌ Will NOT suggest times like "How about 2 PM?"
❌ Will NOT accept dates beyond 2 days
