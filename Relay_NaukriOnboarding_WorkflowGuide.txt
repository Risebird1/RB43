================================================================================
RELAY.APP  NAUKRI PROSPECTIVE INTERVIEWER ONBOARDING — CONFIGURATION GUIDE
================================================================================

OVERVIEW
--------
This Relay workflow monitors a Gmail inbox for emails from Naukri.com
(@naukri.com senders) containing candidate profiles for prospective
interviewers. It extracts candidate details from the email body/subject,
uploads the attached resume to Google Drive, and POSTs the data to a
webhook for further processing (employment verification, AI analysis,
onboarding).

The Naukri email format is a structured notification with fields:
  - Subject line: Contains job title, company, experience, location, salary
    Example: "NVite : Naukri.com: Online Interviewer-GIS Engineer, Development
    Team Lead, RSS Softech / gistec, 18 Years & 0 Months, Hyderabad, 40 L"
  - Body: Structured fields (Name, Location, Past Experience, Notice Period,
    Education, KeySkills, etc.)
  - Attachment: Resume file (PDF/DOC/DOCX)


================================================================================
STEP-BY-STEP RELAY SETUP
================================================================================

────────────────────────────────────────────────
STEP 1 — Gmail Trigger
────────────────────────────────────────────────
  Trigger:  Gmail → "New Email" (batch or per-email)
  Account:  Your monitoring Gmail account
  Filter:   From contains "@naukri.com"
             Subject contains "NVite" or "Naukri.com"
  Options:  Mark as read after processing ← optional
  
  This ensures only Naukri notification emails are processed.


────────────────────────────────────────────────
STEP 2 — AI Extract (GPT-5.4 Mini)
────────────────────────────────────────────────
  Action: "AI Agent" or "Generate text" step (depending on your Relay plan)
  Model:  GPT-5.4 Mini
  Input:  Full email body + email subject
  
  PROMPT / INSTRUCTIONS:
  ──────────────────────
  You are a data extraction assistant. You receive a Naukri.com job application
  notification email. Extract the following fields from the email body and
  subject line. Return ONLY a JSON object with these exact keys.

  Fields to extract:

  | Key               | Source                              | Notes                                    |
  |-------------------|-------------------------------------|------------------------------------------|
  | candidate_name    | Email body ("Name" field)           | Full name of the candidate               |
  | location          | Email body ("Location" field)       | City or location                         |
  | past_experience   | Email body ("Past Experience" field) | Previous role and company               |
  | notice_period     | Email body ("Notice Period" field)   | e.g. "2 Months", "Immediate"            |
  | education         | Email body ("Education" field)      | Degree and institution                   |
  | key_skills        | Email body ("KeySkills" field)      | Comma-separated list of skills          |
  | current_role      | Email body or subject               | Current designation and company          |
  | experience_years  | Email body ("EE" / experience)      | e.g. "18 Years & 0 Months"             |
  | salary            | Email body or subject               | e.g. "40 L", "40 Lacs"                 |
  | mag_name          | Subject line                        | The job title/specialization ONLY,       |
  |                   |                                     | e.g. "GIS Engineer" from                 |
  |                   |                                     | "Online Interviewer-GIS Engineer"        |
  |                   |                                     | Strip the "Online Interviewer-" prefix   |

  IMPORTANT for mag_name:
  - The subject format is: "NVite : Naukri.com: Online Interviewer-{JOB_TITLE}, ..."
  - Extract ONLY the job title part (after "Online Interviewer-" and before the comma)
  - This maps to a MasterAssessmentGroup name in the Risebird system
  - Example: "Online Interviewer-GIS Engineer" → mag_name = "GIS Engineer"
  - If "Online Interviewer-" prefix is not present, use the first comma-separated
    field from the subject after "Naukri.com:"

  Output format: strict JSON, no markdown fences, no extra text.
  Example output:
  {
    "candidate_name": "Balaji Reddi",
    "location": "Hyderabad",
    "past_experience": "Senior Developer at GISTEC",
    "notice_period": "2 Months",
    "education": "B.Tech / B.E. at Jawaharlal Nehru Technological University (JNTU)",
    "key_skills": "Web Development, Desktop Application Development, React.js, C#, ESRI Development",
    "current_role": "Development Team Lead at RSS Softech / gistec",
    "experience_years": "18 Years & 0 Months",
    "salary": "40 L",
    "mag_name": "GIS Engineer"
  }


────────────────────────────────────────────────
STEP 3 — Check for Resume Attachment
────────────────────────────────────────────────
  Condition: Does the email have attachments?
  Branch into Path A (has attachment) or Path B (no attachment).


────────────────────────────────────────────────
STEP 4A — Upload Resume to Google Drive (Path A only)
────────────────────────────────────────────────
  Action:  Google Drive → "Upload file"
  Account: Your Google Drive account
  Folder:  "RB Naukri Prospective Interviewers" (create this folder first)
  File:    First attachment from the email
  Name:    {candidate_name} - {mag_name} - Resume
           (use AI output fields from Step 2)


────────────────────────────────────────────────
STEP 5 — HTTP POST to Webhook
────────────────────────────────────────────────
  Action:  HTTP Request → POST
  URL:     https://portal.risebird.io/NaukriOnboarding/Webhook
  
  Headers:
    Content-Type:    application/json
    X-Relay-Secret:  {your-shared-secret}
  
  Body (JSON):
  {
    "sender_email":     "{{trigger.from_email}}",
    "subject":          "{{trigger.subject}}",
    "mail_content":     "{{trigger.body_text}}",
    "received_at":      "{{trigger.date}}",
    "candidate_name":   "{{step2.candidate_name}}",
    "location":         "{{step2.location}}",
    "past_experience":  "{{step2.past_experience}}",
    "notice_period":    "{{step2.notice_period}}",
    "education":        "{{step2.education}}",
    "key_skills":       "{{step2.key_skills}}",
    "current_role":     "{{step2.current_role}}",
    "experience_years": "{{step2.experience_years}}",
    "salary":           "{{step2.salary}}",
    "mag_name":         "{{step2.mag_name}}",
    "resume_link":      "{{step4a.file_url | default: 'None'}}",
    "has_attachment":   true/false  ← from the branch condition
  }
  
  PAYLOAD FIELD DATA TYPES:
    sender_email     : string
    subject          : string
    mail_content     : string (plain text body)
    received_at      : string (ISO 8601 datetime)
    candidate_name   : string
    location         : string
    past_experience  : string
    notice_period    : string
    education        : string
    key_skills       : string (comma-separated)
    current_role     : string
    experience_years : string
    salary           : string
    mag_name         : string
    resume_link      : string (Google Drive URL or "None")
    has_attachment   : boolean (true/false)


────────────────────────────────────────────────
STEP 5B — HTTP POST (Path B — No Attachment)
────────────────────────────────────────────────
  Same as Step 5 above, but:
    "resume_link":    "None"
    "has_attachment":  false


================================================================================
SERVER-SIDE CONFIGURATION
================================================================================

1. Add to appsettings.json:
   "RelayWebhook": {
     "NaukriOnboardingSecret": "<generate-a-strong-secret>"
   }

2. The webhook endpoint is:
   POST /NaukriOnboarding/Webhook
   - [AllowAnonymous] (no session required)
   - Validates X-Relay-Secret header
   - Creates a NaukriProspectiveInterviewer record

3. The management dashboard is:
   GET /NaukriOnboarding/Index
   - Requires login session
   - Shows all prospects with filters
   - "Manage" modal has 4-step pipeline:
     Step 1: Parse Resume & Check Duplicate
     Step 2: Employment Verification (Signzy)
     Step 3: AI Resume Fitment Analysis
     Step 4: Onboard (create profile + AG + channels + ack email)


================================================================================
IMPORTANT NOTES
================================================================================

• The Naukri email does NOT contain the candidate's actual email or phone number.
  These are extracted from the resume PDF in Step 1 of the management pipeline
  (server-side).

• The "mag_name" must match a MAGName in the MasterAssessmentGroup table.
  If it doesn't match, the operator will see a warning in the management modal.

• The resume is uploaded to Google Drive by Relay and the link is passed to
  the server. The server may also re-upload it to Azure Blob Storage if the
  operator uploads a new version.

• Unlike the Interviewer Availability workflow, this flow does NOT skip stale
  emails (no 46-hour cutoff) since Naukri notifications are application-driven,
  not conversation-driven.
